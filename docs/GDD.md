## 1. 한 줄 소개

**시간의 균열에 휘말려 서기 80년 로마 콜로세움에 떨어진 플레이어가 검투사로 살아남는 이야기.** 검투사와 맹수로 시작해 신화 속 괴물, 그리고 다른 시대와 차원의 존재까지 상대하며 강해진다.

## 2. 디자인 기둥

| 기둥 | 설명 |
|---|---|
| **짧고 강렬한 런** | 한 판 20~30분, 20웨이브. "딱 한 판만 더"를 유도한다. |
| **상점에서 완성하는 빌드** | 웨이브 사이 상점에서 무기, 아이템, 얼티밋 강화, 슬롯 확장을 결정한다. 성장의 중심은 상점이다. |
| **클래스 정체성** | 클래스마다 강점과 약점이 뚜렷하다. 같은 상점 물건도 클래스에 따라 가치가 달라진다. |
| **한 방의 카타르시스** | 게이지를 모아 쓰는 강력한 얼티밋으로 위기를 뒤집는다. |
| **점점 무너지는 시간** | 로마 → 신화 → 차원 붕괴로 서사와 난이도가 함께 올라간다. |

## 3. 세계관 · 스토리

### 3.1 배경
- 서기 80년, 티투스 황제가 콜로세움 개장을 기념해 100일간 경기를 연다.
- 플레이어는 유물 **"크로노스의 모래시계"** 파편에 닿아 이 시대로 떨어진다. 노예로 붙잡혀 검투사 양성소(루두스)에 팔려 간다.
- **클래스는 루두스에서 받는 검투사 훈련 유형**이다. 같은 시간여행자라도 어떤 전투 방식을 익혔는지가 클래스로 표현된다.

### 3.2 3막 구조
1. **1막 — 피와 모래의 경기장 (로마)**: 검투사와 맹수를 상대한다. 승리할수록 몸속 파편이 반응하고 경기장에 균열이 생긴다.
2. **2막 — 신화가 깨어나다 (균열)**: 균열 너머에서 신화 속 괴물이 쏟아진다. 황제와 관중은 이를 "신들의 경기"로 여기며 열광한다.
3. **3막 — 시간의 붕괴 (차원)**: 여러 시대와 차원이 겹친다. 모래시계를 노리는 **"시간을 삼키는 자"**와 최종 결전을 벌인다.

### 3.3 엔딩 (후보)
귀환 엔딩 / 잔류 엔딩 / 시간 수호자 진엔딩(최고 위험도 클리어)

## 4. 핵심 게임 루프

```
[클래스 선택] → [시작 무기 선택 (클래스 장착 제한 내)]
        ↓
┌─▶ [웨이브 전투] 이동으로 회피, 무기는 자동 공격
│      · 적 처치 → 포인트(데나리우스) + 경험치
│      · 처치와 피해로 얼티밋 게이지 충전 → 가득 차면 발동
│        ↓
│   [레벨업 보상 선택 (스탯)]
│        ↓
│   [★ 상점] 무기 · 아이템 · 얼티밋 강화 · 슬롯 확장
└──────── 다음 웨이브 ──┘
        ↓ 막 보스 처치 → 막 전환 (스토리 + 유물 선택)
        ↓ 20웨이브 최종 보스 처치 or 사망
[결과 → 명성(메타 화폐) → 해금]
```

### 4.1 런 구조 (3막 · 20웨이브)

| 막 | 웨이브 | 시대 | 보스 (막의 끝) |
|---|---|---|---|
| 1막 | 1~6 | 로마 콜로세움 | **6웨이브 — 황제의 챔피언** |
| 2막 | 7~13 | 신화의 균열 | **13웨이브 — 미노타우로스** |
| 3막 | 14~20 | 차원 붕괴 | **20웨이브 — 시간을 삼키는 자 (최종)** |

- **일반 웨이브**: 20초로 시작해 최대 60초까지 늘어난다. 제한 시간 동안 버티면 클리어다.
- **보스 웨이브**: 시간 제한 없이 보스를 처치하면 클리어다. 그동안 잡몹은 계속 나온다.
- **엘리트**: 막 중반 웨이브(3~4, 10~11, 16~18)에 등장한다. 처치하면 상점 할인권이나 유물 조각을 준다.
- **막 전환**: 보스를 처치하면 짧은 스토리 컷신이 나오고, **유물 3개 중 1개**를 고른 뒤 상점으로 간다.

### 4.2 조작 (PC + 게임패드)

| 행동 | 키보드/마우스 | 게임패드 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 스틱 |
| 얼티밋 발동 | Space | RB (또는 Y) |
| 수동 조준 (옵션) | 마우스 | 오른쪽 스틱 |
| 일시정지 | Esc | Start |
| 상점 · UI 탐색 | 마우스 클릭 | D패드/스틱 + A/B (모든 UI 포커스 이동 지원) |

- 공격은 기본적으로 **자동 조준, 자동 발사**다.
- 모든 키는 리바인딩할 수 있다. 입력은 Godot `InputMap` 액션으로 추상화한다.

## 5. 클래스

### 5.1 설계 원칙
- 각 클래스에는 **컨셉 → 장착 제한 → 강점 → 페널티 → 고유 얼티밋**이 한 세트로 있다.
- 장착 제한은 무기의 **공격 유형(근접 / 원거리)**과 **계열 태그**로 판정한다.
- 페널티는 강점과 반대 방향에 걸어서 빌드 방향을 자연스럽게 유도한다.

### 5.2 클래스 목록 (초안)

| 클래스 | 컨셉 | 장착 제한 | 강점 | 페널티 | 고유 얼티밋 |
|---|---|---|---|---|---|
| **검사** (무르밀로) | 근접 전문 검투사 | **근접 무기만** | 근접 피해 +25%, 근접 공격 속도 +15% | 원거리 피해 -50%, 원거리 관련 스탯 효율 -50% | **검풍난무**: 주변을 연속으로 베는 회전 검기 |
| **궁수** (사기타리우스) | 원거리 저격수 | **원거리 무기만** | 원거리 피해 +25%, 사거리 +30% | 최대 체력 -20%, 근접 피해 -50% | **화살비**: 넓은 범위에 화살 폭우 |
| **그물투사** (레티아리우스) | 그물과 삼지창의 견제가 | 장창 · 투척 계열 우대 (제한 없음) | 회피 +15%, 둔화 효과 +50% | 방어 -5 | **포세이돈의 그물**: 넓은 범위의 적을 포박하고 받는 피해를 증가시킴 |
| **중장투사** (세쿠토르) | 방패와 중갑의 탱커 | 제한 없음 | 최대 체력 +30%, 방어 +8 | 이동 속도 -15%, 공격 속도 -10% | **철벽 돌진**: 방패로 전방을 밀어붙이며 무적 |
| **맹수조련사** (베스티아리우스) | 맹수와 함께 싸움 | 제한 없음 | **보조 슬롯 +1로 시작**, 소환수 피해 +30% | 본인 무기 피해 -20% | **맹수 대행진**: 사자 떼가 경기장을 가로지름 |
| **점술사** (하루스펙스) | 신의 힘을 빌림 | 신화 계열 우대 | 신력 피해 +30%, 행운 +20 | 근접·원거리 피해 -25%, 최대 체력 -10% | **유피테르의 낙뢰**: 화면 전체 무작위 낙뢰 |
| **시간여행자** | 균형형 (초보자용) | 제한 없음 | 상점 새로고침 웨이브당 1회 무료 | 없음 (특성도 약함) | **시간 역행**: 3초 전 위치와 체력으로 돌아가며 경로상 적에게 피해 |
| **크로노맨서** (해금) | 시간을 다루는 자 | 시간 계열 우대 | 얼티밋 충전 속도 +50% | 최대 체력 -25% | **시간 정지**: 5초간 적 정지, 이 동안 준 피해가 해제 시 폭발 |
| **버서커** (해금) | 거대한 양손 대검의 광전사 | **양손 무기 1개로 손 슬롯 고정** (손 무기 2개 불가) | 양손 무기 피해 +50%, 체력이 낮을수록 공격 속도 증가, **받은 피해 충전 ×2** | 손 무기 1개뿐, 방어 -5, 체력 재생 불가 | **광폭화**: 일정 시간 흡혈 + 대검 범위 2배, 받는 피해 일부 무시 |

> 이후 Brotato처럼 극단적인 컨셉의 클래스를 추가할 수 있다(예: 맨손 투사).

## 6. 무기 & 슬롯 시스템

### 6.1 슬롯 구조

```
┌──────────── 무기 슬롯 (최대 6) ────────────┐
│ [왼손] [오른손] │ [보조1] [보조2] [보조3] [보조4] │
│  기본 2개 (양손)  │   확장으로만 개방 (0 → 최대 4)   │
└──────────────────┴─────────────────────────────┘
          [얼티밋 슬롯 1개 — 클래스 고유, 별도]
```

- **손 슬롯 (2개, 기본 개방)**: 손에 드는 무기만 장착한다(검, 창, 활, 투척 무기 등).
- **보조 슬롯 (0~4개, 확장 필요)**: 손에 들지 않는 무기만 장착한다.

| 보조 무기 유형 | 예시 |
|---|---|
| 부유형 | 주위를 도는 단검, 수호 방패, 떠다니는 모래시계 |
| 장착형 | 어깨 장착 석궁(만코발리스타), 등에 메는 화염 분사기 |
| 소환형 | 늑대, 독수리, 정령, 미래 드론 |

### 6.2 보조 슬롯 확장 방법
| 경로 | 예시 |
|---|---|
| 상점 구매 | **"장착대"** 상품: 보조 슬롯 +1, 구매할 때마다 가격 상승 |
| 아이템 | 가죽 어깨띠(보조 +1, 이동 속도 -3%), 조련사의 호루라기(소환형 전용 +1) |
| 클래스 특성 | 맹수조련사는 보조 +1로 시작 |
| 유물 | 막 전환 보상으로 슬롯 확장 유물 등장 |

### 6.3 양손 무기 (페널티형)
- 거대 대검 같은 **양손 무기는 손 슬롯 2칸을 하나의 무기가 차지**한다. 무기 개수가 줄어드는 것 자체가 페널티다.
- 그 대가로 한 번의 공격이 매우 강하고 범위가 넓다.
- 기본적으로 **버서커 전용**이다. 다른 클래스는 장착할 수 없고, 버서커는 손 슬롯에 양손 무기 1개만 쓸 수 있다.
- 버서커도 보조 슬롯은 다른 클래스처럼 확장할 수 있다. 부족한 화력은 보조 무기로 보충하는 구조다.

### 6.4 무기 속성
- **공격 유형**: 근접 / 원거리. 클래스 장착 제한 판정에 쓴다.
- **계열 태그**: 검, 장창, 투척, 활, 맹수, 신화, 시간. 같은 계열을 여러 개 장착하면 세트 보너스가 생긴다.
- **등급**: I → II → III → IV. 상점에서 같은 무기 2개를 합치면 다음 등급이 된다.
- **시대 진행**: 1막에는 로마 무기, 2막부터 신화 무기, 3막부터 시대착오 무기(머스킷, 레이저 블레이드)가 상점에 등장한다.

## 7. 얼티밋 시스템

### 7.1 기본 규칙
- 무기 슬롯과 별개인 **얼티밋 슬롯 1개**가 있다. 클래스 고유 얼티밋이 장착된다(5.2 참고).
- **게이지 0~100%**가 가득 차면 발동할 수 있다. 위력은 무기보다 확실히 강하다. 보스전과 위기 탈출의 핵심이다.
- 게이지는 **웨이브가 바뀌어도 유지**된다. 아껴 두었다가 보스 웨이브에 쓰는 전략이 가능하다.

### 7.2 게이지 충전
| 충전원 | 기본 충전량 (초안) |
|---|---|
| 일반 적 처치 | +0.5% |
| 엘리트 처치 | +10% |
| 적에게 준 피해 | 피해 100당 +1% |
| **내가 받은 피해** | 최대 체력의 1%를 잃을 때마다 +1% (많이 맞을수록 빨리 참) |
| 관중 호응 최고 단계 | 충전량 ×1.5 |

> 수치는 프로토타입에서 조정한다. 목표는 **일반 웨이브 1~2회당 1번 발동**이다.

### 7.3 얼티밋 강화 (상점)
| 단계 | 효과 | 비고 |
|---|---|---|
| Lv1 | 기본 | 시작 |
| Lv2 | 피해 +30% | |
| Lv3 | 범위 또는 지속 시간 증가 + **추가 효과 1** | 예: 검풍난무가 출혈을 부여 |
| Lv4 | 피해 +30%, 충전 필요량 -15% | |
| Lv5 | **각성**: 얼티밋의 형태가 바뀌는 강화 | 예: 화살비가 불화살비로 바뀌어 화염 장판 생성 |

- 강화 비용은 단계마다 올라간다. 무기와 아이템 구매와 **같은 예산을 두고 경쟁**하는 것이 핵심 고민 지점이다.

### 7.4 충전 경로 특화
충전 경로(처치 / 준 피해 / 받은 피해)마다 효율을 따로 올릴 수 있다. 플레이 스타일에 맞춰 게이지가 차는 방식을 고르게 하려는 장치다.

| 수단 | 예시 |
|---|---|
| 클래스 특성 | 버서커: 받은 피해 충전 ×2 · 궁수: 준 피해 충전 ×1.3 · 맹수조련사: 소환수 처치도 충전에 포함 |
| 상점 「충전 각인」 | 처치 / 준 피해 / 받은 피해 중 하나의 충전 효율 +25% (각인마다 최대 3회) |
| 아이템 | 상처투성이 갑옷(받은 피해 충전 +50%, 방어 -3) · 투기장의 함성(전체 충전 +20%, 방어 -2) |

## 8. 상점 (루두스) — 핵심 성장 화면

### 8.1 화면 구성
```
┌────────────────────────────────────────────────────────┐
│  보유 포인트: 💰 1,240     웨이브 7/20     [다음 웨이브 ▶] │
├────────────────────────────────────────────────────────┤
│ [진열대]  상품 4개 (무기/아이템 혼합)                     │
│   [상품1] [상품2] [상품3] [상품4]   🔒 잠금 · 🔄 새로고침   │
├──────────────────────────┬─────────────────────────────┤
│ [얼티밋 강화]  Lv2 → Lv3   │ [장착대] 보조 슬롯 +1         │
│   비용 600                │   비용 400                   │
├──────────────────────────┴─────────────────────────────┤
│ [내 장비] 손 슬롯 2 + 보조 슬롯 · 합성 · 판매              │
│ [내 스탯] 클래스 보정 포함 최종 스탯                       │
└────────────────────────────────────────────────────────┘
```

### 8.2 규칙
- **포인트(데나리우스)**: 웨이브 중 적이 떨어뜨린 것을 줍는다. 웨이브가 끝나면 남은 것을 자동 회수한다.
- **진열대**: 4개 상품이 나온다. 클래스가 장착할 수 없는 무기는 진열 확률을 낮추고, 진열되더라도 "장착 불가"로 표시한다.
- **잠금**: 상품을 다음 웨이브까지 보존한다.
- **새로고침**: 비용이 웨이브 내에서 점점 오른다.
- **합성**: 같은 무기 같은 등급 2개 → 다음 등급
- **판매**: 구매가의 일부를 환급한다.
- **상인 메르쿠리우스**: 정체를 숨긴 상업의 신이다. 막이 바뀔 때마다 대사로 스토리 복선을 전달한다.

### 8.3 레벨업 (상점 진입 전)
- 경험치가 차면 **스탯 강화 카드 4장 중 1장**을 고른다. 여러 번 레벨업하면 연속으로 고른다.

## 9. 스탯 & 아이템

### 9.1 스탯
최대 체력 · 체력 재생 · 흡혈 · 피해량% · 근접 피해 · 원거리 피해 · 신력 피해 · 공격 속도 · 치명타 · 사거리 · 방어 · 회피 · 이동 속도 · 행운 · 후원(웨이브당 추가 포인트) · **얼티밋 충전량**

### 9.2 아이템
- 개수 제한 없는 패시브다. 대부분 **장점과 단점을 함께** 가진다. 등급은 일반 / 희귀 / 영웅 / 전설이다.
- 예: 로마 투구(방어 +3, 이동 속도 -3%) · 박카스의 포도주(공격 속도 +15%, 웨이브마다 체력 -5) · 투기장의 함성(얼티밋 충전량 +20%, 방어 -2)

## 10. 차별화 시스템

### 10.1 관중 호응
- 연속 처치, 노피격, 엘리트 처치, 얼티밋으로 여러 적을 한 번에 처치하면 호응이 오른다.
- 호응이 높으면 관중이 선물(회복, 포인트, 임시 버프)을 던지고 얼티밋 충전량이 늘어난다.
- 호응이 낮으면 황제가 추가 맹수와 함정을 가동한다. 위험이 커지는 대신 보상도 늘어난다.

### 10.2 시간 균열 이벤트
- 웨이브 도중 균열이 열려 다른 시대의 엘리트가 출현한다. 처치하면 유물 조각을 준다.

### 10.3 경기장 기믹
- 1막: 창 함정, 맹수 우리
- 2막: 미궁 벽, 석화 시선
- 3막: 시간 정지 구역, 중력 반전

## 11. 적 디자인

### 11.1 1막 — 로마 (보스: 황제의 챔피언)
노예 검투사(직진) · 늑대(빠른 무리) · 사자(멈칫 후 돌진) · 곰(고체력) · 레티아리우스(그물 둔화) · 궁수(거리 유지 사격)
- **보스 황제의 챔피언**
  - 1페이즈: 돌진과 회전베기
  - 2페이즈: 부하 검투사 소환, 관중이 경기장에 무기를 투척

### 11.2 2막 — 신화 (보스: 미노타우로스)
하피(급강하) · 켄타우로스(원형 기동 사격) · 용 이빨 전사(1회 부활) · 사이렌(끌어당김) · 메두사(시선 석화) · 히드라(엘리트, 머리 분열)
- **보스 미노타우로스**
  - 1페이즈: 벽까지 돌진하고 충돌 시 기절
  - 2페이즈: 경기장에 미궁 벽 생성

### 11.3 3막 — 차원 붕괴 (최종 보스: 시간을 삼키는 자)
드라우그(얼음 장판) · 아누비스 수호자(저주 낙인) · 사무라이 망령(순간이동 베기) · 기계병(레이저) · 시간 그림자(플레이어의 과거 경로 추적)
- **최종 보스 시간을 삼키는 자**: 페이즈마다 시대를 전환한다(로마 → 신화 → 미래). 앞선 보스들의 패턴을 변형해 사용한다.

## 12. 메타 진행
- 런이 끝나면 **명성**을 얻는다. 클래스, 무기, 아이템, 얼티밋 변형을 해금한다.
- **위험도 0~5**: 클래스별로 클리어할 때마다 다음 단계가 열린다.
- **도감**: 적, 무기, 아이템 기록과 스토리 텍스트가 있다.

## 13. 아트 · 사운드

### 13.1 아트 방향
- **픽셀 아트 캐릭터** 기반 2D 탑다운 시점(살짝 내려다보는 3/4 뷰)이다.
- 스타일 레퍼런스: **파이널판타지 레조넌스**
  - 디테일이 살아 있는 고품질 픽셀 캐릭터와 부드러운 애니메이션을 목표로 한다.
  - 레퍼런스 이미지를 받아 구체적인 해상도, 팔레트, 라이팅 기준을 정할 예정이다.
- 스프라이트 크기 기준 (안)

| 대상 | 크기 |
|---|---|
| 플레이어 | 48×48 |
| 일반 적 | 32~48 |
| 엘리트 | 64 |
| 보스 | 128 이상 |

- 클래스마다 실루엣이 확실히 달라야 한다(투구, 방패, 그물, 활 등).
- 시대별 색감
  - 로마: 모래, 붉은 대리석
  - 신화: 푸른 대리석, 금빛
  - 차원: 보라, 네온 글리치
- 픽셀 아트 렌더링: 텍스처 필터 Nearest, 정수배 스케일링, 고정 기준 해상도에 맞춰 확대한다.

### 13.2 사운드
- 관중 함성의 크기가 호응 게이지와 연동된다.
- 막마다 BGM 편성이 바뀐다(타악기 → 합창 → 신스).
- 얼티밋 발동 시 전용 연출과 사운드를 넣는다.

## 14. 기술 설계 (Godot 4)

### 14.1 폴더 구조 (안)
```
project/
├── scenes/   main/ arena/ player/ enemies/ weapons/ projectiles/ ultimates/ ui/
├── scripts/
│   ├── autoload/      # GameState, RunState, EventBus, SaveManager
│   └── components/    # HealthComponent, HitboxComponent, StatSheet ...
├── data/              # .tres 리소스 — 데이터 주도 설계
│   ├── classes/       # ClassData: 장착 제한, 스탯 보정, 얼티밋 참조
│   ├── weapons/       # WeaponData: 공격 유형, 슬롯 유형(손/양손/보조), 계열, 등급
│   ├── ultimates/     # UltimateData: 단계별 효과
│   ├── items/  enemies/  waves/  acts/
└── assets/            # sprites, audio, fonts
```

### 14.2 핵심 원칙
- **데이터 주도 설계**: 클래스, 무기, 얼티밋, 아이템, 적, 웨이브, 막을 `Resource`로 정의한다. 코드를 고치지 않고 밸런싱한다.
- **장착 규칙 검증 모듈**: `ClassData`의 제한 조건과 `WeaponData`의 슬롯 유형·공격 유형을 대조하는 함수 하나로 통일한다. 상점, 장착, 진열 확률이 모두 같은 함수를 쓴다.
- **StatSheet**: 기본값 → 클래스 보정 → 아이템 → 유물 → 버프 순으로 합산한다. 클래스 페널티("원거리 스탯 효율 -50%")도 여기서 처리한다.
- **오브젝트 풀링**: 적, 투사체, 드롭 아이템을 풀링해 수백 개 객체에서도 성능을 유지한다.
- **EventBus**: 처치, 피해, 웨이브 종료 이벤트를 시그널로 전파한다. 얼티밋 게이지, 관중 호응, UI가 같은 이벤트를 구독한다.
- **입력**: `InputMap` 액션으로 키보드와 게임패드를 동시에 지원한다. 모든 UI는 포커스 기반 탐색을 지원한다.
