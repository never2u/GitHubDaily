# 크로노 글래디에이터 (가제) — 게임 기획서 v0.1

> 엔진: Godot 4.x (GDScript) · 장르: 탑다운 아레나 서바이벌 로그라이트 · 레퍼런스: *Brotato*

---

## 1. 한 줄 소개

**시간의 균열에 휘말려 서기 80년 로마 콜로세움에 떨어진 주인공이 검투사로 살아남는 이야기.** 검투사와 맹수로 시작해 신화 속 괴물과 다른 시대·차원에서 넘어온 존재까지 상대하며 강해진다.

## 2. 디자인 기둥 (Design Pillars)

| 기둥 | 설명 |
|---|---|
| **짧고 강렬한 런** | 한 판 20~30분. 웨이브마다 20~60초 동안 버티는 구조로, Brotato처럼 "딱 한 판만 더"를 유도한다. |
| **빌드 만들기의 재미** | 무기 6슬롯, 아이템, 스탯 성장을 조합한다. 시대를 넘나드는 무기와 시너지가 핵심이다. |
| **점점 무너지는 시간** | 런이 진행될수록 경기장이 로마 → 신화 → 차원 붕괴로 변한다. 서사와 난이도 곡선이 같이 올라간다. |
| **관중이 지켜보는 무대** | 콜로세움만의 시스템인 "관중 호응"으로 플레이 스타일에 보상을 준다. Brotato와 차별화되는 지점이다. |

## 3. 세계관 · 스토리

### 3.1 배경
- **서기 80년**, 티투스 황제가 콜로세움(플라비우스 원형경기장) 개장을 기념해 100일간 경기를 연다.
- 현대인 주인공은 정체불명의 유물 **"크로노스의 모래시계"** 파편을 건드렸다가 이 시대로 떨어진다.
- 낯선 옷차림 때문에 노예로 붙잡혀 검투사 양성소(루두스)에 팔려 간다. 살아남으려면 경기장에서 싸울 수밖에 없다.

### 3.2 전개 (3막 구조)
1. **1막 — 피와 모래의 경기장 (로마)**
   검투사와 맹수를 상대하며 이름을 알린다. 주인공이 승리할 때마다 몸에 박힌 모래시계 파편이 반응하고, 경기장 곳곳에 작은 균열이 생기기 시작한다.
2. **2막 — 신화가 깨어나다 (균열)**
   균열 너머에서 미노타우로스, 메두사, 켄타우로스 같은 신화 속 존재가 쏟아져 나온다. 황제와 관중은 이를 신들의 경기로 여기며 열광한다. 주인공은 파편의 힘을 다루는 법을 깨닫는다.
3. **3막 — 시간의 붕괴 (차원)**
   다른 시대와 차원이 콜로세움 위로 겹친다. 북유럽의 망자, 이집트의 수호자, 미래의 기계병까지 나타난다. 최종적으로 모래시계를 노리는 **"시간을 삼키는 자"**와 맞선다.

### 3.3 엔딩 방향 (후보)
- **귀환 엔딩**: 모래시계를 복원해 현대로 돌아간다.
- **잔류 엔딩**: 로마의 전설적인 검투사로 남는다.
- **시간 수호자 엔딩**: 최고 난이도를 클리어하면 열리는 진엔딩이다.

> 스토리는 런 사이 짧은 컷신, 상인·동료 NPC 대사, 도감 텍스트로 전달한다. 플레이 흐름을 끊지 않는 것이 원칙이다.

## 4. 핵심 게임 루프

```
[캐릭터(검투사 유형) 선택] → [시작 무기 선택]
        ↓
┌─▶ [웨이브 전투: 제한 시간 동안 생존, 자동 공격, 이동으로 회피]
│        ↓ 적 처치 → 데나리우스(화폐) + 경험치 드롭
│   [웨이브 종료: 레벨업 보상 선택 → 상점(루두스)에서 무기·아이템 구매]
└──────── 다음 웨이브 ──┘
        ↓ 20웨이브 클리어 or 사망
[결과 → 명성(메타 화폐) 획득 → 캐릭터·무기·아이템 해금]
```

### 4.1 조작
- **이동만 직접 조작**한다(WASD / 게임패드 스틱). 공격은 장착한 무기가 가장 가까운 적을 자동으로 노린다.
- 옵션으로 수동 조준 모드를 제공한다(마우스 방향).

### 4.2 런 구조 (20웨이브)
| 웨이브 | 시대 | 주요 적 | 비고 |
|---|---|---|---|
| 1~6 | 로마 콜로세움 | 검투사, 맹수 | 6웨이브: **엘리트 — 황제의 챔피언** |
| 7~13 | 신화의 균열 | 그리스·로마 신화 괴물 | 13웨이브: **보스 — 미노타우로스** |
| 14~19 | 차원 붕괴 | 다른 시대·차원의 존재 | 시대가 섞여 등장 |
| 20 | 최종전 | **시간을 삼키는 자** | 최종 보스 |

- 웨이브 시간은 20초에서 시작해 점점 늘어나 최대 60초가 된다.
- 웨이브가 끝나면 바닥에 남은 화폐를 자동으로 회수한다. 일부는 다음 웨이브로 이월된다(Brotato의 "수확" 개념).

## 5. 시스템 상세

### 5.1 스탯
| 스탯 | 설명 |
|---|---|
| 최대 체력 / 체력 재생 / 흡혈 | 생존 |
| 피해량 % | 모든 공격에 적용 |
| 근접 피해 / 원거리 피해 / **신력 피해** | 무기 계열별 추가 피해 (신력 = 원소·마법 계열) |
| 공격 속도 / 치명타 확률 / 사거리 | 공격 |
| 방어 / 회피 | 받는 피해 감소, 회피 확률 |
| 이동 속도 | 기동성 |
| 행운 | 드롭과 상점 등급에 영향 |
| **후원** | 웨이브마다 들어오는 추가 수입 (Brotato의 수확) |
| **관중 호응** | 6장 참고 |

### 5.2 무기
- **최대 6개 장착**한다. 같은 무기 2개를 합치면 등급이 오른다(I → II → III → IV).
- 무기에는 **계열 태그**가 붙고, 같은 계열을 여러 개 장착하면 세트 보너스가 생긴다.

| 계열 | 예시 무기 | 세트 보너스 예시 |
|---|---|---|
| 검 (Blade) | 글라디우스, 시카, 스파타 | 치명타 +% |
| 장창 (Polearm) | 삼지창, 하스타, 사리사 | 사거리 +, 넉백 |
| 투척 (Thrown) | 필룸, 투석구, 그물 | 적 둔화 |
| 활 (Bow) | 복합궁, 스키타이 활 | 관통 +1 |
| 맹수 (Beast) | 조련 채찍, 사자 소환 | 소환수 피해 + |
| 신화 (Divine) | 제우스의 번개, 포세이돈의 삼지창, 아폴론의 활 | 신력 피해 + |
| 시간 (Chrono) | 머스킷, 레이저 블레이드, 모래시계 단검 | 쿨다운 감소, 시간 감속 |

> **핵심 아이디어**: 시대가 진행될수록 상점에 신화 무기, 이후에는 시대착오적인 무기(화약, 미래 무기)가 등장한다. 세계관의 시간 붕괴를 빌드 변화로 체감하게 한다.

### 5.3 아이템 (패시브)
- 개수 제한 없이 쌓이는 패시브 아이템이다. 대부분 **장점과 단점을 함께** 가진다.
  - 예: **로마 투구**는 방어 +3, 이동 속도 -3%
  - 예: **박카스의 포도주**는 공격 속도 +15%, 매 웨이브 체력 -5
  - 예: **메두사의 눈물**은 피격 시 10% 확률로 주변 적을 석화시키지만, 최대 체력이 -5 줄어든다.
- 등급은 일반 / 희귀 / 영웅 / 전설 4단계다.

### 5.4 레벨업
- 경험치가 차면 웨이브 종료 후 **스탯 강화 카드 4장 중 1장**을 고른다.

### 5.5 상점 (루두스)
- 무기·아이템 4개가 진열된다. 새로고침(비용이 점점 오름)과 잠금 기능이 있다.
- 상인 NPC **"메르쿠리우스"**는 상업의 신이다. 정체를 숨기고 있으며 스토리상 복선 역할을 한다.

## 6. 차별화 시스템

### 6.1 관중 호응 (Crowd Favor)
- 연속 처치, 노피격, 엘리트 처치 같은 **화려한 플레이**를 하면 호응 게이지가 오른다.
- 게이지가 높으면 관중이 경기장에 **선물을 던져 준다**(회복약, 화폐, 임시 버프).
- 웨이브가 끝날 때 호응이 최고 단계면 **황제의 엄지척**을 받아 특별 보상을 고른다.
- 호응이 너무 낮으면 황제가 **추가 맹수를 풀거나 경기장 함정을 가동**한다. 위험하지만 보상도 커진다.

### 6.2 시간 균열 이벤트
- 웨이브 도중 무작위로 균열이 열려 **다른 시대의 엘리트**가 튀어나온다.
- 처치하면 **유물(Relic)**을 얻는다. 런 하나에 2~3개를 얻으며, 빌드 방향을 크게 바꾸는 강력한 효과를 가진다.

### 6.3 경기장 기믹
- 1막: 바닥에서 솟는 창 함정, 맹수 우리 문이 열림
- 2막: 미궁 벽 생성, 메두사의 석화 시선
- 3막: 시간 정지 구역, 중력 반전 구역

## 9. 메타 진행

- 런이 끝나면 성과에 비례해 **명성**을 얻는다.
- 명성으로 할 수 있는 것: 캐릭터·무기·아이템 해금, 시작 무기 선택지 확장
- **위험도 (Danger) 0~5**: 클리어할 때마다 다음 단계가 열린다. 적 강화, 엘리트 추가, 관중 페널티 강화가 적용된다(Brotato의 위험도 시스템).
- **도감**: 처음 만난 적이나 아이템을 기록한다. 스토리 텍스트가 해금된다.

## 10. 아트 · 사운드 방향

- **2D 탑다운**, 단순하고 가독성 높은 캐릭터를 쓴다(Brotato처럼 몸통 + 무기 구조).
- 시대별 색감
  - 로마: 모래색, 붉은 대리석
  - 신화: 푸른 대리석, 금빛
  - 차원: 보라색, 네온 글리치
- 수백 마리의 적이 동시에 나와도 플레이어, 적, 투사체가 명확히 구분되어야 한다.
- 사운드: 관중 함성의 크기가 호응 게이지와 연동된다. 시대마다 BGM 악기 편성이 바뀐다(타악기 → 합창 → 신스).

## 11. 기술 설계 (Godot 4)

### 11.1 폴더 구조 (안)
```
project/
├── scenes/
│   ├── main/          # 타이틀, 메인 메뉴
│   ├── arena/         # 전투 씬, 웨이브 매니저
│   ├── player/
│   ├── enemies/
│   ├── weapons/
│   ├── projectiles/
│   └── ui/            # HUD, 상점, 레벨업
├── scripts/
│   ├── autoload/      # GameState, RunState, EventBus, SaveManager
│   └── components/    # HealthComponent, HitboxComponent 등
├── data/              # .tres 리소스 (데이터 주도 설계)
│   ├── weapons/
│   ├── items/
│   ├── enemies/
│   ├── characters/
│   └── waves/
└── assets/            # sprites, audio, fonts
```

### 11.2 핵심 원칙
- **데이터 주도 설계**: 무기, 아이템, 적, 웨이브를 `Resource`(`WeaponData`, `ItemData`, `EnemyData`, `WaveData`)로 정의한다. 코드를 고치지 않고 밸런스를 조정할 수 있다.
- **컴포넌트 구조**: 체력, 히트박스, 이동 등을 컴포넌트 노드로 분리해 재사용한다.
- **오브젝트 풀링**: 적, 투사체, 드롭 아이템을 풀링해 수백 개 객체를 다뤄도 성능을 유지한다.
- **EventBus (Autoload)**: 적 처치, 피격, 웨이브 종료 같은 이벤트를 시그널로 전파해 UI와 시스템 간 결합을 낮춘다.
- **스탯 계산**: 기본값 → 캐릭터 보정 → 아이템 보정 → 버프 순으로 합산하는 `StatSheet`를 둔다.
